# Code Recall

Offline flashcards for reviewing what I learned in CareerFoundry's Frontend, Full-Stack and Python courses. Every card is based on code from my own projects.

**Open it:** https://cody-ayers.github.io/code-recall/

- 162 cards in 13 sections, from HTML & CSS to Django
- Multiple-choice and flip-card modes
- Spaced repetition: cards you miss come back sooner
- Installable PWA: add it to your home screen and it works offline

Built with plain HTML, CSS and JavaScript, a web app manifest and a service worker.
